# Tiny Chess Engine (≤4 KB)

Python chess engine for [make.fun tiny-chess-01](https://make.fun/bounty/tiny-chess-01).

- Alpha-beta + quiescence + null-move pruning
- Late Move Reductions (LMR) + history heuristic + killers
- Piece-square tables
- Opponent-aware node budgets
- Fixed-node search (deterministic)
- Pure stdlib
- Packed main.py under 4 KB
